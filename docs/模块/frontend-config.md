# frontend-config

状态：已确认。上级：[架构与组装](../架构与组装.md)。

## 1. 职责

- 负责：编辑和保存全部配置（[C06](../契约/C06-配置模型.md)）：实体、页面（字段设置、按钮、拖动编辑表单布局）、操作、规则、审批流、角色、菜单、字典、Lookup、导出；保存前校验，把错误定位到配置的具体位置。
- 不负责：配置的校验规则和保存（config）。

## 2. 所有权

| 类别 | 内容 |
|---|---|
| 代码 | `frontend/src/modules/config/` |
| 状态 | 配置编辑界面的状态 |

## 3. 对外契约

导出 C11 的 `FrontendModule`，路由 `/config`；调用 [C09 第 3 节](../契约/C09-HTTP接口.md)的接口。

- FC-01：只对管理员角色显示。
- FC-02：保存即生效；保存前可以先调用校验接口，校验错误定位到配置的具体路径。
- FC-03：表单布局用 24 列网格拖动编辑（grid-layout-plus），保存后所有人共用。
- FC-04：行权限的编辑界面与旧系统一致：可视化条件和自定义 SQL 两种方式。
- FC-05：审批流编辑覆盖 C06 7.1 的全部配置项，其中审批详情"修改内容"的主表和从表逐列配置（C06 7.6：选字段、填列标题、调整顺序）：触发的保存操作（与旧系统一样，在"哪些保存操作触发送审"对话框中勾选修改、新增、删除，可多选，默认只选修改，列表中显示为"保存操作"列）、触发条件、级别和入口、审批人、关联查询及参数、选择方式、展示内容、冻结、批准后动作和字段映射、通知。
- FC-06：规则和旧系统一样按表单编辑：规则类型、作用字段、条件（可视化条件或表达式）、计算表达式和分支（C06 第 5 节）；不做图形化的规则编辑器。
- FC-07：新建页面向导：选择上级菜单、填写页面名称和编码、选择单表或主从；选择主表的视图和写入表，导入列并调整标题、可见、可编辑；添加明细表并指定关联列；预览后生成（config CF-14）。序列不存在时提示用户先建序列。
- FC-08：实体编辑中可以配置必须审批的字段规则、默认值和对比；审批流编辑中可以配置 SQL 审批人、节点动作和动作参数。

## 4. 依赖

契约 C06、C09、C11。

## 5. 内部流程

读取配置项 → 编辑 → 校验 → 保存 → 显示新版本号。

## 6. 接入方式

- 联调后才能确认：保存后，已打开的业务页面无需刷新即可生效（批次 D）。
