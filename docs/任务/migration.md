# migration 任务

模块说明：[migration](../模块/migration.md)。状态和证据的写法见[工程约定第 4 节](../工程约定.md)。

相关业务例子：E02、E10、E11（[业务例子](../业务例子.md)）。测试先行、真实约束证据和完成前复核见[工程约定](../工程约定.md)第 5–7 节。

### T-MG-1 读取旧元数据与生成配置

- 归属与目标：实现 MG-01、MG-07、MG-08、MG-10、MG-11 中记下来源的部分，以及 MG-02 中的人工改写清单。
- 前置输入：开始前 T-CT-1、T-DB-1；C06 经用户确认。
- 负责范围：`backend/src/cost_platform/migration/` 的读取和生成；命令 `platform migrate generate`。
- 交付物：按 C06 生成的配置项（实体、页面、角色、菜单、字典、Lookup、导出）及每项的来源（旧表和行）；人工改写清单；完整的业务表清单（交 T-DB-3）。
- 接入责任：生成的配置由 T-MG-3 导入。
- 验收标准：重复运行生成逐字节相同的结果；生成的每个配置项都能按 C06 解析，C06 第 1.1 节要求必须写的字段都已写出，按旧系统行为取值的字段列在迁移报告中，取不到值的列入人工改写清单（MG-10）；清单中的每一项能追溯到旧数据的位置；新平台没有对应配置项的旧配置（例如 `SUMMARY_CONFIG`）列入人工改写清单并注明需要新增的能力；同一张表对应多个旧实体的（例如成本核算的材料和包材明细都在 `T_COST_PINGGU_DTL`），列出区分方式交用户确认。
- 状态与证据：未开始。

### T-MG-2 规则、行权限与审批的转换

- 归属与目标：实现 MG-02 的候选逃生舱清单、审批确认清单，以及 MG-03。
- 前置输入：开始前 T-MG-1。
- 负责范围：migration 中规则、行权限和审批流的转换。
- 交付物：旧 CALC、VALIDATION、EDITABLE、GRID_STYLE 规则转成 C06 第 5 节的写法（例如 `CostPinggu.APEX_PL` 改为 `master.APEX_PL`）；成本核算 12 个虚拟列的计算规则按 MG-12 从虚拟列表达式转换；行权限原样迁移；旧审批定义转成 C06 第 7 节，两个价格同步的存储过程动作改为通用动作；转换出的规则和审批流按 MG-10 写出必须写的字段（例如规则的 `order`、审批流参数的 `required`）；候选逃生舱清单；审批确认清单。
- 接入责任：由 T-MG-3 导入。
- 验收标准：旧数据中出现的每种公式写法至少一个转换测试；无法转换的不生成近似结果，列入清单；转换后的两个审批流与 C06 7.4、7.5 一致。
- 状态与证据：未开始。

### T-MG-3 导入与对账

- 归属与目标：实现 MG-04、MG-05，以及 MG-11 中的拒绝清单。
- 前置输入：开始前 T-MG-1、T-MG-2；用户确认三份清单。
- 负责范围：命令 `platform migrate import`、`platform migrate reconcile`。
- 交付物：导入；导入被拒绝时的拒绝清单；对账报告（每类差异的数量，差异归入 `D:\chonggou\my-project\公式差异.md` 的某一条或列为未解释）。
- 接入责任：经 `ConfigImporter`、`AccountImporter`、`PersonalConfigImporter` 写入，T-AS-8 接入真实实现。
- 验收标准：模拟验证：导入的数据与生成结果一致，重复导入不重复写入；两条旧记录生成了类型和编码相同的配置项（例如两个旧页面各自定义了同一个字典）时，整批被拒绝、一项都没有写入，拒绝清单列出这两项，各自给出来源表和行，原因说明同一批中类型和编码重复；某一项引用不存在的配置项时，拒绝清单列出这一项的来源和原因；真实联调中对账没有未解释的差异，有时交用户决定。
- 状态与证据：未开始。

### T-MG-4 切换手册与演练

- 归属与目标：实现 MG-06。
- 前置输入：开始前 T-MG-3。
- 负责范围：`docs/切换手册.md`。业务表的列（只有页面显示的列，虚拟列为普通列）在复制时已经确定（db-core 的 DB-03）。
- 交付物：切换手册（停止旧系统写入、让 d_cg 的业务数据跟上 cmx（方式见 migration 的待确认）、迁移配置和账号、核对、回退）。
- 接入责任：T-AS-8 演练。
- 验收标准：在 d_cg 上按手册演练一次切换和一次回退：切换后各表行数不变，抽查单据的非计算字段不变、计算字段与对账一致；回退后业务表的结构和数据恢复到切换前。
- 状态与证据：未开始。
