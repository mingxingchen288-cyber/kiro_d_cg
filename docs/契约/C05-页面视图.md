# C05 页面视图

版本：v3。维护：contracts。状态：已确认。

config 在保存配置时，按（页面、角色）生成页面视图。前端经 `GET /api/pages/{pageCode}/view`（[C09](C09-HTTP接口.md)）读取，后端经配置快照（[C08](C08-后端端口.md)）读取。同一（页面、角色、版本）的内容不变。


| 字段 | 说明 |
|---|---|
| `layout` | `single`：单表页，`details` 为空；`masterDetail`：主从页 |
| `detailMode` | 明细的默认显示方式，`tabs` 或 `stack`；用户自己的选择存在个人配置里（C09） |
| `audit` | 本页面的命令是否记录审计差异 |
| `fields[].type` | `text`、`number`、`date`、`datetime`、`boolean` |
| `fields[].scale` | 数值的显示小数位，只用于显示，不改变计算和保存的值；非数值为 null |
| `fields[].source` | `erp`：ERP 列；`own`：平台自有列 |
| `master.erpRow`、`details[].erpRow` | 实体的 ERP 行标识（C06 第 2 节），没有时省略。有时前端在该列等于 `value` 的行上把 ERP 列显示为只读，其他行按 `editable` |
| `fields[].visible`、`editable`、`required` | 实体、页面（含主表区或明细区、Tab）和角色三层叠加后的结果：可见、可编辑只能收紧，必填只能增加 |
| `fields[].width`、`pinned` | 默认列宽和固定位置（`left`、`right` 或 null）；个人列配置由前端叠加 |
| `fields[].dictType` | 字典类型，值从字典下拉中选 |
| `fields[].lookup` | 写法同 C06 第 3 节的 `lookup`：编码、回填映射（键为本页字段，值为 Lookup 结果的列），以及 `multiple`、`filter`、`fillBack`；后三项为默认值（`false`、无、`true`）时省略 |
| `grid` | AG Grid 企业版选项：侧边栏、框选、分组字段 |
| `formLayout` | 24 列网格：`x` 从 0 起，`x + w` 不超过 24，`w`、`h` 不小于 1；为空时按字段顺序排列 |
| `master.buttons`、`details[].buttons` | 本区域中当前角色有权限的按钮，按页面配置的顺序。`key` 为权限键（C06 第 8 节）；`action` 为内置动作 `copyRow`、`saveGridConfig`，或业务动作（`operation` 给出引用的操作）；`requiresSelection` 为 true 时没有选中行就不可用。内置动作的 `requiresSelection` 按 config 的 CF-03 给出，业务动作的取页面配置中的值 |
| `systemButtons` | 当前角色有权限的页面级按钮：`save`、`addRow`、`deleteRow`、`advancedSearch`。`addRow`、`deleteRow` 显示在页面配置里放了这两个按钮的区域，没有选中行时是否可用按 config 的 CF-03；没有 `save` 时整页只读 |

规则：

- 字段可见性只用于显示：后端返回的行包含不可见字段，由前端隐藏；查询、筛选、排序和高级查询只能使用可见字段。
- 个人层（列宽、顺序、固定、显隐和明细显示方式）不在页面视图里，经 C09 的个人配置接口单独读写。
- 前端按 `rulesPack` 下载规则包（[C07](C07-规则内核接口.md)）。
- 按钮只用于显示；保存、新增、删除、复制和按钮操作的权限都由后端再检查一次（C06 第 8 节）。

契约测试：本文样例能被后端模型和前端类型无损解析；`formLayout` 越界的样例被 config 拒绝。
