# C10 实时事件

版本：v2。维护：contracts。状态：已确认。

## 1. 后端进程之间：Redis 频道

频道名为 `{ns}:events`，`{ns}` 取 `.env` 中的 `PLATFORM_REDIS_NAMESPACE`。发布方调用 realtime 的 `RealtimePublisher`（[C08](C08-后端端口.md)），realtime 写入频道；每个后端进程的 realtime 订阅这个频道，再推给本进程登记的连接。

```json
{"eventId": "6c2f0d6e-1b7a-4b55-9a1e-2f8f3c1d4e5a", "topic": "config.changed", "audience": {"pages": ["COST_PINGGU"]}, "payload": {"pages": ["COST_PINGGU"], "version": 13}}
```

| topic | audience | payload | 发布方 |
|---|---|---|---|
| `config.changed` | `pages`：受影响的页面 | `pages`、`version` | config |
| `notification` | `users`：接收人的用户编号 | `deliveryId`、`title`、`body`、`link` | delivery |
| `session.revoked` | `users` 或 `sessions` | `reason`：`accountDisabled`、`roleRevoked` 或 `loggedOut` | identity |

## 2. 浏览器与后端：WebSocket `/ws`

- 认证：握手时带会话 Cookie，由 identity 的 `Authenticator` 校验；Origin 必须与 `.env` 中的 `PLATFORM_ALLOWED_ORIGINS` 一致，否则拒绝握手。
- 浏览器发送：

```json
{"type": "subscribe", "pages": ["COST_PINGGU"]}
{"type": "unsubscribe", "pages": ["COST_PINGGU"]}
{"type": "ping"}
```

- 服务端推送：

```json
{"topic": "config.changed", "eventId": "1f2e3d4c-5b6a-4978-8695-a4b3c2d1e0f9", "payload": {"pages": ["COST_PINGGU"], "version": 13}}
{"topic": "notification", "eventId": "2a3b4c5d-6e7f-4a8b-9c0d-1e2f3a4b5c6d", "payload": {"deliveryId": "3b4c5d6e-7f8a-4b9c-8d0e-2f3a4b5c6d7e", "title": "您有来自于物料清单及成本页面，业务单据为115的审批", "body": "", "link": "/approval/203"}}
{"topic": "session.revoked", "eventId": "4c5d6e7f-8a9b-4c0d-9e1f-3a4b5c6d7e8f", "payload": {"reason": "accountDisabled"}}
{"type": "pong"}
```

- 浏览器按 `eventId` 去重；通知再按 `deliveryId` 去重。
- 会话失效后，服务端关闭该连接，不再推送。

## 3. 契约测试

- 第 1、2 节的每种消息都能被后端和前端的类型无损解析。
- realtime 只把事件推给 audience 匹配的连接：`pages` 匹配订阅了该页面的连接，`users` 匹配该用户的连接，`sessions` 匹配该会话的连接。
