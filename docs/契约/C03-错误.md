# C03 错误

版本：v2。维护：contracts。状态：已确认。

## 1. 错误响应体

```json
{
  "code": "FIELD_NOT_WRITABLE",
  "message": "有字段不能修改",
  "details": [
    {"message": "PRICE 是 ERP 列，不能修改", "entity": "COST_GOODS_PRICE", "rowKey": "115", "clientRowId": null, "field": "PRICE", "approvalId": null, "configType": null, "configKey": null, "path": null}
  ]
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | 字符串 | 取第 2 节的错误码之一 |
| `message` | 字符串 | 给用户看的中文说明 |
| `details` | 数组，可以为空 | 每项都有 `message`、`entity`、`rowKey`、`clientRowId`、`field`、`approvalId`、`configType`、`configKey`、`path` 九个字段，用不到的为 null。前六个用于定位到行和字段，被冻结时 `approvalId` 指明冻结它的审批；后三个用于配置校验，指明配置项的类型、编码和内容中的位置，`path` 例如 `levels[0].entries[1].approvers` |

响应中不出现 `ORA-` 错误文本、SQL 文本和调用栈。

## 2. 错误码与 HTTP 状态

每个错误码只对应一个 HTTP 状态。

| HTTP | 错误码 | 含义 |
|---|---|---|
| 400 | INVALID_REQUEST | 请求格式不对，例如缺少请求键 |
| 401 | SESSION_REQUIRED | 没有有效会话 |
| 401 | SESSION_ROLE_REVOKED | 会话选定的角色已被撤销 |
| 401 | LOGIN_FAILED | 用户名或密码错误；账号不存在时也返回这个错误 |
| 403 | PERMISSION_DENIED | 无权执行该操作，或访问超出行权限 |
| 403 | CSRF_FAILED | 写请求的 CSRF 令牌无效 |
| 403 | ORIGIN_REJECTED | 请求来源不是平台前端 |
| 403 | ROLE_SELECTION_REQUIRED | 还没有选定角色 |
| 404 | NOT_FOUND | 对象不存在，或在行权限范围外 |
| 409 | DOCUMENT_BUSY | 等待单据锁超时 |
| 409 | REQUEST_IN_PROGRESS | 同一请求键的命令仍在处理 |
| 409 | FROZEN_BY_APPROVAL | 要修改的单据被审批冻结，或这次要发起的审批需要冻结的单据已在另一个未结束的审批中 |
| 409 | RECONFIRM_REQUIRED | 审批人确认后结果发生变化，需要重新确认 |
| 409 | ROW_NOT_FOUND | 要修改的行已被删除，且配置为拒绝 |
| 409 | APPROVAL_REQUIRED | 修改命中必须审批的字段规则，但没有进入审批，或者不是从允许的页面保存 |
| 422 | IDEMPOTENCY_KEY_REUSED | 同一请求键提交了不同的内容 |
| 422 | RULE_REJECTED | 规则拒绝 |
| 422 | VALIDATION_FAILED | 必填为空、格式不合法，或配置校验不通过 |
| 422 | FIELD_NOT_WRITABLE | 提交了不可写的字段 |
| 503 | CONFIG_UNAVAILABLE | 读不到配置 |
| 503 | DATABASE_UNAVAILABLE | 数据库不可用或连接断开 |
| 500 | INTERNAL_ERROR | 其他错误 |

## 3. 契约测试

- 第 2 节每个错误码都有一个样例响应，后端按样例生成，前端按样例解析并定位。
- 后端把 Oracle 错误映射为平台错误码：等锁超时为 DOCUMENT_BUSY，连接断开或数据库不可用为 DATABASE_UNAVAILABLE，其余为 INTERNAL_ERROR。
