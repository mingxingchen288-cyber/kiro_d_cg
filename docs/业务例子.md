# 业务例子

每个例子都是可以直接判断对错的验收条件。任务的验收标准引用这里的编号；"模拟"列的任务用替代实现验证，"真实"列的任务在 Oracle、Redis 和浏览器上验证，两者分开记录（[工程约定](工程约定.md)第 4 节）。

例子中的单据号、物料号以迁移后 d_cg 中的真实数据为准，表中的值用于说明。
